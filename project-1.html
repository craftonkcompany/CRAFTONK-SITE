Craftonk Analyzer

✦ проекты

CRAFTONK Analyzer - основная задача, это помочь руководству находить слабых сотрудников в компании, что позволит более перспективным кадрам занять их место. Наше приложение использует специальные алгаритмы для отслеживания времени посещения приложений, что позволяет создать статистику. Для автоматизации просмотра статистики на большом количестве устройств у администратора есть возможность, добавить ( пока в ручную) всю статистику рабочих и выбрать приоритетную программу, и получить результат о самом эффективном сотруднике и о самом слабом.

Также наше приложение собирает данные о подключении usb утройств(usb накопители), чтобы передать администратору о том, что файлы с usb были добавлены на компьютер/ были перенесены на usb. Эта функция сделана в целях сохранения данных внутри компании, а в случае утечки обнаружение подозреваемых.

Приложение использует примитивные модели нейронных сетей для автоматизации, для анализа данных и прочее. Написано на языке программирования python, использована библиотека flet для GUI и другие.
